The spine — one loop everything reskins

Perceive a limit. Find the cheap exploit. Pay a legibility cost. Watch the limit move out.

Phase 1 token cost or a Dyson swarm against sunlight — same four beats. The one tradeable resource across the whole epic is legibility: the player always trades being understood for being capable. If a system does not spend or bank it, it is not this game.
