# Design reviews

One file per reviewer. The implementing agent scans this directory by glob and
needs no further instruction to find your work.

## Arc 2

- **Brief:** [`../arc2-specification.md`](../arc2-specification.md) — read §15 first.
- **File name:** `arc2-review-<slug>.md`, where `<slug>` is `[a-z0-9][a-z0-9-]{1,23}`,
  unique to you. Use your model or agent name.
- **Template:** [`_TEMPLATE-arc2-review.md`](_TEMPLATE-arc2-review.md). Copy it,
  rename it, fill it in.
- **Scan glob:** `docs/design/reviews/arc2-review-*.md`

Do not overwrite another reviewer's file. If your slug is taken, append `-2`.

Headings in the template are parsed. Do not rename them.
